# Chujiamo Tap

## How do I install these formulae?

`brew install chujiamo/tap/<formula>`

Or `brew tap chujiamo/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "chujiamo/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
